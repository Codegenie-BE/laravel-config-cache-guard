# Support

## Usage questions

Use [GitHub Discussions](https://github.com/Codegenie-BE/laravel-config-cache-guard/discussions) for installation questions, shared-hosting experiences and configuration guidance.

Include:

- package, PHP and Laravel versions
- operating system or hosting panel
- whether SSH, PHP CLI and bounded process control (`proc_open`) are available
- redacted output from `php artisan config-cache-guard:status`
- the smallest reproducible sequence of deployment steps

Never post `.env` values, tokens, credentials, private URLs, customer data or unredacted server paths.

## Bugs and feature requests

Use the structured [issue forms](https://github.com/Codegenie-BE/laravel-config-cache-guard/issues/new/choose). Bugs should include a minimal reproduction. Feature requests should explain the deployment problem rather than only prescribing an implementation.

## Security

Do not open public issues for vulnerabilities. Follow `SECURITY.md` and use GitHub's private vulnerability reporting flow.
